# Sawariya Diagnostic Lab — Brand Guidelines

## Identity
- **Brand:** Sawariya Diagnostic Lab
- **Promise:** Detect • Diagnose • Deliver
- **Design direction:** Clinical Peacock Editorial
- **Tone:** calm, precise, warm, locally trustworthy

## Colors
| Role | Hex | Use |
|---|---|---|
| Laboratory red | `#C62828` | SAWARIYA, primary booking actions |
| Red hover | `#A61E1E` | Primary hover/active |
| Diagnostic blue | `#155E9A` | DIAGNOSTIC, navigation, links, secondary actions |
| Blue hover | `#0F4775` | Secondary hover/active |
| Deep navy | `#102A43` | Structural dark surfaces, footer, dialogs |
| Promise brown | `#7A4B2A` | Detect • Diagnose • Deliver and warm editorial accents |
| Cream | `#FFF9F3` | Page canvas |
| White | `#FFFFFF` | Cards, forms, dialogs |
| Ink | `#102A43` | Primary text |
| Muted ink | `#455468` | Secondary text |
| Warm border | `#D7C7B8` | Dividers and input borders |

## Typography
- **Display/headings:** Outfit
- **Body/UI:** DM Sans
- Large headings use tight tracking; body copy uses comfortable 1.5–1.6 leading.
- Mobile form text stays at least 16px to avoid iOS zoom.

## Usage rules
- Red is the decisive action color; do not use it for every highlight.
- Blue is the navigation/diagnostic information color.
- Brown is a restrained promise/editorial color.
- Status colors remain semantic and separate from brand identity.
- Use the Peacock red→brown→blue gradient only in the logo/hero signature.
- Prefer opaque readable surfaces; reserve blur/transparency for floating chrome.
- Never introduce a new hardcoded brand hex without updating this file and the token layer.

## Accessibility
- Target WCAG AA for normal text and AAA where practical.
- Never communicate state by color alone.
- Focus indicators must remain visible on cream, white, red, blue, and navy.
- Honor reduced motion and reduced transparency preferences.
