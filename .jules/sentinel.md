## 2025-03-05 - Fix Path Traversal / SSRF in FLabs integration API
**Vulnerability:** In `server.ts`, the `/api/lis/download-report` endpoint takes `patientId` and `reportId` from the request body and interpolates them directly into a `fetch` call to an external API (FLabs) without encoding them. This allows an attacker to perform Path Traversal (using `../`) and Server-Side Request Forgery (SSRF) to access unintended paths on the FLabs API while utilizing the server's legitimate authentication token.
**Learning:** Never trust client-supplied input, especially when it is used to construct URLs for server-side requests. Even if an API endpoint seems to only interact with external services, failing to encode parameters can lead to SSRF and data exposure.
**Prevention:** Always validate and sanitize input variables. Use `encodeURIComponent()` for variables that will be injected into URL paths or queries to prevent path traversal and manipulation of the request structure.
